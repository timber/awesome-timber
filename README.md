# Awesome Timber [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of projects built on [Timber](https://github.com/timber/timber), the library that lets you write WordPress themes with Twig templates.

Every project listed here works with Timber 2 and has been updated in the last two years.

## Starter themes

- [Timber Starter Theme](https://github.com/timber/starter-theme) - The official "_s" for Timber, a dead-simple theme you can build anything from.
- [Flynt](https://github.com/flyntwp/flynt) - Component based starter theme, powered by ACF Pro and Timber.
- [Chisel](https://github.com/xfiveco/generator-chisel) - Generator for Timber themes, with a component based structure and a modern front-end build.
- [Timberland](https://github.com/cearls/timberland) - Theme using Timber, ACF Pro, Vite, Tailwind and Alpine.js.

## Frameworks

- [Lumberjack](https://github.com/Rareloop/lumberjack) - MVC framework for WordPress, built on Timber, for developers coming from Laravel and similar frameworks.
- [Conifer](https://github.com/sitecrafting/conifer) - Library plugin for object-oriented WordPress development on top of Timber.
- [Foehn](https://github.com/studiometa/foehn) - WordPress framework powered by Tempest, with auto-discovery for hooks, post types and blocks.
- [timber-kit](https://github.com/parisek/timber-kit) - Starter kit library for Timber themes: configurable base site class, ACF helpers, image resizer, ACF block renderer, WPML and WPForms helpers.

## Blocks

- [Timber ACF WP Blocks](https://github.com/palmiak/timber-acf-wp-blocks) - Create Gutenberg blocks from Twig templates and ACF fields.

## Images

- [Timmy](https://github.com/mindkomm/timmy) - Advanced image handling: image sizes, responsive images and resizing on the fly.

## WooCommerce

- [Timber WooCommerce integration](https://github.com/mindkomm/timber-integration-woocommerce) - Use Twig templates for WooCommerce.

## Debugging

- [Timber Rings](https://github.com/timber/rings) - Query Monitor panel that profiles your Twig templates and shows which template line rendered any element of the page.
- [Timber Dump Extension](https://github.com/nlemoine/timber-dump-extension) - Symfony VarDumper for Timber, a nicer `{{ dump() }}` in your templates.

## Translation

- [wp-i18n-twig](https://github.com/timber/wp-i18n-twig) - WP-CLI command to extract translatable strings from Twig files.

## Performance

- [Timber WebLink Extension](https://github.com/nlemoine/timber-weblink-extension) - Twig functions to manage the Link HTTP header for resource hints and preloading.

## Learning

- [Timber documentation](https://timber.github.io/docs/v2/) - Official guides and reference for Timber 2.
- [Learn Timber Theme](https://github.com/timber/learn-timber-theme) - Minimal theme that serves as an entry point for learning Timber.
