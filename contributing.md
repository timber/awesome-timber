# Contribution guidelines

Thanks for helping keep this list useful. Please make sure your pull request follows these rules.

## What can be listed

- The project is built on Timber, or made to be used with it.
- It works with Timber 2.
- It has been updated in the last two years. Projects that stop being maintained are removed.
- It's reusable. Themes or code written for a single website don't belong here.

## How to add a project

- One pull request per project.
- Add it at the end of the section it belongs to.
- Use the format `- [Name](link) - Description.`
- Keep the description short, start it with a capital letter and end it with a period. Don't start it with "A" or "An", and don't repeat the project name.
- Link to the repository, not to a website that only redirects to it.

## Removing a project

Open a pull request that removes it and says why (no update in two years, no Timber 2 support, archived repository).
